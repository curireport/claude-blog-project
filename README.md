# 미래온 블로그 프로젝트

미래온 블로그의 기획 및 진행 현황을 정리한 프로젝트입니다.

## 파일 구성

- `미래온_블로그_프로젝트_현황.html` — 프로젝트 현황 대시보드 (브라우저에서 열어서 확인)
- `티스토리/` — 구글 검색용 티스토리 블로그 자료
  - `01_첫30편_키워드_제목목록.md` — 첫 30편 키워드·제목과 8주 발행 순서
  - `02_미래온글_재가공_템플릿.md` — 미래온 글을 티스토리 글로 재가공하는 원칙, 글 구조, 체크리스트, AI 프롬프트
  - `03_첫글_고교학점제_과목선택.md` — 재가공으로 만든 첫 글 완성 원고

## 사용 방법

`미래온_블로그_프로젝트_현황.html` 파일을 브라우저로 열면 현재 진행 상황을 확인할 수 있습니다.
