# 미래온 블로그 프로젝트

미래온 블로그의 기획 및 진행 현황을 정리한 프로젝트입니다.

## 파일 구성

- `미래온_블로그_프로젝트_현황.html` — 프로젝트 현황 대시보드 (브라우저에서 열어서 확인)
- `티스토리/` — 구글 검색용 티스토리 블로그 자료 (미래온과 분리 운영, 자세한 목록은 `티스토리/README.md`)
  - `기획/` — 첫 30편 키워드·제목 목록, 네이버 글 재가공 템플릿
  - `원고/` — 발행용 원고 30편 (미래온 글 재가공 12편 + 새로 쓴 18편)

## 사용 방법

`미래온_블로그_프로젝트_현황.html` 파일을 브라우저로 열면 현재 진행 상황을 확인할 수 있습니다.
