🌱 미래온 성장연구소 · 상담 전 자가진단
━━━━━━━━━━━━━━━━━━━━━━━━━━━

**상담 신청 전에 해보는 자가진단 (학부모용)**
"아이 문제"라고 느끼지만, 어디를 도와야 할지 정리해 봅니다

학부모 상담에서 가장 자주 나오는 말은
"뭐라도 해주고 싶은데 뭘 해야 할지 모르겠어요"입니다.

이 자가진단은 그 막막함을 네 갈래로 나눕니다.
자녀를 평가하는 도구가 아니라,
부모로서 지금 어디에 힘이 부치는지 보는 도구입니다.

소요 시간은 3분 정도입니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️ 이 자가진단은 상담을 준비하기 위한 참고용 체크리스트입니다.
정식 검사나 진단을 대체하지 않으며,
점수가 높다고 잘못 키웠다는 뜻이 아닙니다.
"상담에서 어디부터 이야기하면 좋을지"를 정하기 위한 것입니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 점수 매기는 법

각 문항이 요즘 나에게 얼마나 해당되는지 숫자로 적습니다.

  0 = 전혀 아니다
  1 = 가끔 그렇다
  2 = 자주 그렇다
  3 = 매우 그렇다

영역별 네 문항을 더하면 영역 점수(0~12점)가 됩니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ A 영역 · 자녀 이해

A1. 자녀가 무엇을 좋아하고 어떤 생각을 하는지 잘 모르겠다. ( )
A2. 대화를 시도해도 겉도는 느낌이고 속마음을 듣기 어렵다. ( )
A3. 자녀의 기질·성향을 어떻게 대해야 할지 감이 없다. ( )
A4. 자녀가 요즘 힘들어 보이는데 이유를 모르겠다. ( )

A 영역 합계: (       ) / 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ B 영역 · 소통 방식

B1. 진로·공부 이야기를 꺼내면 대화가 자주 갈등으로 끝난다. ( )
B2. 잔소리인 걸 알면서도 같은 말을 반복하게 된다. ( )
B3. 자녀와 이야기할 때 감정 조절이 잘 안 된다. ( )
B4. 어떻게 말해야 아이가 마음을 열지 방법을 모르겠다. ( )

B 영역 합계: (       ) / 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ C 영역 · 진로·진학 지원

C1. 입시 정보가 너무 많아 무엇이 우리 아이에게 맞는지 판단이 안 선다. ( )
C2. 자녀의 진로·진학 방향을 어떻게 도와야 할지 모르겠다. ( )
C3. 고교학점제·전형 변화 등 제도를 따라가기 벅차다. ( )
C4. 지원을 하고는 있는데 방향이 맞는지 늘 불확실하다. ( )

C 영역 합계: (       ) / 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ D 영역 · 부모 자신의 마음

D1. 자녀 문제로 불안하거나 잠이 잘 오지 않는 날이 있다. ( )
D2. 다른 집 아이와 자꾸 비교하게 된다. ( )
D3. 내가 잘못 키운 건 아닌지 죄책감이 들 때가 있다. ( )
D4. 조급함 때문에 아이를 몰아세우고 후회하는 일이 반복된다. ( )

D 영역 합계: (       ) / 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 결과 1 · 영역 점수로 보는 우선순위

  0~3점  → 지금은 큰 어려움이 없는 영역입니다.
  4~7점  → 한 번 짚어볼 만한 영역입니다.
  8~12점 → 상담에서 우선 다루면 좋은 영역입니다.

A·B가 함께 높으면 "관계와 대화부터 풀어야 진로 이야기가 되는" 경우가 많습니다.
C가 특히 높으면 정보·전략 중심의 진학 컨설팅이 먼저 도움이 됩니다.
D가 높으면 부모님 본인을 위한 상담도 함께 권해 드립니다.
아이를 돕기 전에 부모의 마음이 먼저 안정되어야 하는 경우가 많습니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 결과 2 · 영역별 추천 상담 분야

A 영역(자녀 이해) → 학부모 상담 + 자녀 병행 상담 검토
  자녀 기질·성향 이해, 필요 시 자녀 개별 상담 병행

B 영역(소통 방식) → 학부모 상담
  갈등 없이 대화하는 법, 잔소리 아닌 전달, 감정 조절

C 영역(진로·진학 지원) → 학부모 상담 + 진학 컨설팅
  우리 아이에게 맞는 정보 선별, 지원 방향 설계, 제도 정리

D 영역(부모 자신의 마음) → 학부모 상담 + 심리 상담
  불안·비교·죄책감·조급함 다루기

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 결과 3 · 전체 점수로 보는 지금 상태

네 영역 합계(0~48점)를 확인합니다.

  0~12점  → 전반적으로 안정적입니다.
            방향 점검 위주의 단회 상담으로도 충분할 수 있습니다.

  13~28점 → 몇 가지가 겹쳐 있는 상태입니다.
            상담에서 우선순위를 정리하면 도움이 됩니다.

  29~48점 → 여러 영역이 함께 얽혀 있는 상태입니다.
            자녀 상담과 학부모 상담을 함께 고려해 보시길 권합니다.

※ 점수는 부모의 자질을 평가하는 것이 아니라,
   상담에서 어디부터 이야기할지 정하는 참고선입니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 상담 전에 정리해 두면 좋은 3가지

1. 자녀에 대해 요즘 가장 자주 떠오르는 걱정을 한 문장으로 적어보세요.

2. 그 걱정이 뚜렷해진 시점이나 계기가 있다면 언제였나요?

3. 이번 상담이 끝났을 때 "이건 정리됐다" 하고 싶은 것은 무엇인가요?

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 상담 신청 방법

가장 점수가 높았던 영역과 위 3가지 답을 함께
카카오톡 채널이나 블로그 댓글로 남겨주세요.
신청 확인 후 1~2일 내로 일정과 사전 설문을 안내드립니다.

첫 상담은 50분 내외이며, 대면·화상·전화 중 편한 방식으로 진행합니다.
자녀 상담과 학부모 상담을 함께 또는 각각 진행할 수 있습니다.
