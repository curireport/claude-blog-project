━━━━━━━━━━━━━━━━━━━━━━━━━━━

**상담 신청 전에 해보는 자가진단 (중·고등학생용)**
"내가 지금 무엇 때문에 힘든지"부터 정리해 봅니다

상담을 신청할 때 가장 많이 듣는 말이
"뭐가 문제인지도 잘 모르겠어요"입니다.

그럴 때 이 자가진단이 도움이 됩니다.
정답을 맞히는 검사가 아니라,
지금 내 상태를 스스로 들여다보는 도구입니다.

소요 시간은 3분 정도입니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️ 이 자가진단은 상담을 준비하기 위한 참고용 체크리스트입니다.
정식 심리검사나 진단을 대체하지 않으며,
점수가 높다고 문제가 있다는 뜻도 아닙니다.
"지금 어디에 마음이 가 있는지"를 확인하는 용도입니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 점수 매기는 법

각 문항을 읽고 요즘 나에게 얼마나 해당되는지 숫자로 적습니다.

  0 = 전혀 아니다
  1 = 가끔 그렇다
  2 = 자주 그렇다
  3 = 매우 그렇다

영역별로 네 문항의 점수를 더하면 영역 점수(0~12점)가 나옵니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ A 영역 · 진로와 적성

A1. 내가 무엇을 좋아하고 잘하는지 잘 모르겠다. ( )
A2. 하고 싶은 직업이나 분야가 떠오르지 않는다. ( )
A3. 친구들은 진로를 정한 것 같은데 나만 뒤처진 느낌이다. ( )
A4. 진로를 생각하면 막막하거나 불안해진다. ( )

A 영역 합계: (       ) / 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ B 영역 · 진학과 학업 설계

B1. 고교학점제 과목 선택을 어떤 기준으로 해야 할지 모르겠다. ( )
B2. 수시·정시, 학생부종합 같은 전형 용어가 잘 이해되지 않는다. ( )
B3. 지금 내 성적으로 어떤 방향을 잡아야 할지 감이 없다. ( )
B4. 대학·학과를 고를 기준이 없어서 막연하다. ( )

B 영역 합계: (       ) / 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ C 영역 · 학습 습관과 실행

C1. 공부를 시작하기까지 시간이 오래 걸리고 자꾸 미룬다. ( )
C2. 계획을 세워도 끝까지 지키지 못한다. ( )
C3. 책상에 앉아도 집중이 오래 가지 않는다. ( )
C4. 열심히 하는데 성적이 오르지 않아 방법을 바꾸고 싶다. ( )

C 영역 합계: (       ) / 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ D 영역 · 마음과 관계

D1. 요즘 이유 없이 불안하거나 예민하다. ( )
D2. 나를 다른 사람과 자주 비교하고 자신감이 낮다. ( )
D3. 친구 관계에서 반복되는 어려움이 있다. ( )
D4. 지치고 아무것도 하기 싫은 날이 잦다. ( )

D 영역 합계: (       ) / 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 결과 1 · 영역 점수로 보는 우선순위

각 영역 점수를 아래 기준과 비교해 봅니다.

  0~3점  → 지금은 큰 어려움이 없는 영역입니다.
  4~7점  → 한 번 짚어볼 만한 영역입니다.
  8~12점 → 상담에서 우선 다루면 좋은 영역입니다.

점수가 가장 높은 영역이 지금 마음이 가장 많이 가 있는 곳입니다.
두 영역이 비슷하게 높다면, 둘은 대개 연결되어 있습니다.
(예: 진로가 막막해서 공부 실행이 안 되는 경우)

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 결과 2 · 영역별 추천 상담 분야

A 영역(진로와 적성) → 진로 탐색 상담
  적성·흥미 파악, STRONG 직업흥미검사 해석, 진로 방향 설계

B 영역(진학과 학업 설계) → 진학 컨설팅
  고교학점제 과목 전략, 전형 이해, 성적에 맞는 방향 설정

C 영역(학습 습관과 실행) → 학습 코칭
  학습 동기, 공부 습관, 시간 관리, 실행력

D 영역(마음과 관계) → 심리·관계 상담
  불안, 자존감, 친구 관계, 번아웃 — 임상심리 전문가 상담

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 결과 3 · 전체 점수로 보는 지금 상태

네 영역 합계(0~48점)를 확인해 봅니다.

  0~12점  → 전반적으로 안정적입니다.
            가벼운 점검 상담으로도 충분할 수 있습니다.

  13~28점 → 몇 가지 고민이 겹쳐 있는 상태입니다.
            상담에서 우선순위를 함께 정리하면 도움이 됩니다.

  29~48점 → 여러 영역이 함께 얽혀 있는 상태입니다.
            혼자 정리하기보다 상담으로 방향을 잡는 것을 권합니다.

※ 점수는 좋고 나쁨을 가르는 것이 아니라,
   상담에서 어디부터 이야기할지 정하는 참고선입니다.

■ 상담 전에 정리해 두면 좋은 3가지

상담 신청서나 첫 상담 때 아래 세 가지를 함께 가져오면
첫 시간이 훨씬 알차게 진행됩니다.

1. 요즘 머릿속에 가장 자주 떠오르는 고민을 한 문장으로 적어보세요.

2. 그 고민이 시작된 시점이나 계기가 있다면 언제였나요?

3. 이번 상담이 끝났을 때 "이건 정리됐다" 하고 싶은 것은 무엇인가요?

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 상담 신청 방법

가장 점수가 높았던 영역과, 위 3가지 답을 함께
카카오톡 채널이나 블로그 댓글로 남겨주세요.
신청 확인 후 1~2일 내로 일정과 사전 설문을 안내드립니다.

첫 상담은 50분 내외이며, 대면·화상·전화 중 편한 방식으로 진행합니다.
