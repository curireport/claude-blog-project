# 내 강점 찾는 법: 대학생 자기분석 3단계

스펙은 열심히 쌓았습니다. 그런데 "그래서 넌 뭘 잘해?"라는 질문에 말문이 막힙니다.

목표를 이뤄도 기쁨보다 공허함이 먼저 오고, 완벽하게 준비되지 않으면 시작조차 못 합니다. "내가 나를 너무 모르나" 하고 넘기지만, 다음에도 똑같습니다.

강점이 없는 것이 아닐 수 있습니다. **나를 평가하는 기준이 전부 바깥에 있어서 내 안의 신호가 잘 들리지 않는 상태**에 가깝습니다.

> **📌 이 글의 핵심 3줄**
> 1. 강점은 "잘하는 것"보다 **"남들은 힘든데 나는 덜 힘든 것"**에서 찾으세요.
> 2. **가치관 순위 5개**를 정해 두면 선택이 흔들릴 때 기준이 됩니다.
> 3. 완벽주의는 **"일단 제출" 실험**으로 조금씩 줄일 수 있습니다.

## 이런 고민을 하고 있나요?

- [ ] 내 강점과 가치관을 한두 문장으로 설명하기 어렵다
- [ ] 남의 기준에 맞추다 보니 내가 뭘 원하는지 흐려졌다
- [ ] 완벽하게 준비되지 않으면 시작하지 못한다
- [ ] 성취를 해도 만족보다 공허함이 남는다
- [ ] 선택의 이유가 늘 "남들이 그렇게 하니까"에 가깝다

---

## 내 강점이 안 보이는 3가지 이유

### 1. 비교가 기본인 환경에서 오래 지냈다

등수, 학점, 합격 결과로 줄 세워지는 시간이 길면 "내 기준"보다 **"남들 사이에서 내 위치"**로 나를 확인하게 됩니다.

### 2. 결과로만 나를 확인한다

합격이나 수상 같은 결과가 있어야 "나는 괜찮다"고 느끼면, 결과가 없는 기간에는 나를 설명할 말이 사라집니다.

### 3. 완벽주의가 시작을 막는다

"완벽하게 준비되면 시작한다"는 규칙은 사실 **평가받는 순간을 미루기 위한 방어**인 경우가 많습니다.

## 대학생 자기분석 3단계

### 1단계. '남들은 힘든데 나는 덜 힘든 것' 5개 적기

잘하는 것과 애써야 하는 것은 다릅니다. 주변 사람들은 어려워하는데 **나에게는 비교적 자연스러운 일**을 찾아봅니다.

| 질문 | 내 답 |
|---|---|
| 조별 과제에서 자연스럽게 맡게 되는 역할은? | |
| 친구들이 나에게 자주 부탁하는 일은? | |
| 시간 가는 줄 모르고 했던 일은? | |
| 남들이 "그걸 어떻게 해?"라고 물었던 일은? | |
| 힘들었지만 이상하게 지치지 않았던 일은? | |

예를 들어 "조별 과제에서 늘 일정을 정리하게 된다"는 답이 나왔다면 **계획하고 조율하는 힘**이 강점일 수 있습니다.

### 2단계. 가치관 순위 5개 정하기

아래 단어 중 지금 나에게 중요한 것을 **5개 골라 순서대로** 적어 봅니다.

| 가치 단어 |
|---|
| 안정 · 자율 · 성장 · 관계 · 인정 · 기여 · 재미 · 보상 · 전문성 · 균형 · 도전 · 창의 |

| 순위 | 가치 | 이 가치가 중요한 이유 (한 줄) |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |
| 4 | | |
| 5 | | |

진로나 회사를 고를 때 마음이 흔들리면 이 표를 꺼내 봅니다. **1~2순위를 채워 주는 선택**이 대체로 후회가 적습니다.

### 3단계. 강점과 가치관을 한 문장으로 연결하기

> **"나는 (강점)을 잘하고, (가치관)을 중요하게 생각하는 사람이다."**

예) "나는 **복잡한 일을 정리해서 계획하는 것**을 잘하고, **성장과 자율**을 중요하게 생각하는 사람이다."

이 한 문장이 자기소개, 면접, 진로 선택의 출발점이 됩니다.

---

## 완벽주의를 줄이는 '일단 제출' 실험

| 단계 | 할 일 |
|---|---|
| 1 | 과제나 지원서를 **완성도 80% 정도에서** 일단 제출한다 |
| 2 | 결과와 피드백을 기록한다 |
| 3 | 생각했던 것만큼 나빴는지 확인한다 |

대부분은 **생각보다 괜찮았다**는 경험을 하게 됩니다. 이 경험이 쌓이면 시작이 가벼워집니다.

---

## 성취 후 공허하다면 이렇게 점검해 보세요

목표를 이뤘는데도 허전하다면 이렇게 물어봅니다.

- 이 목표는 **누구의 기준**이었나?
- 2단계에서 정한 **내 가치관과 연결**되어 있었나?
- 남들이 가는 길을 **그대로 따라간 것**은 아니었나?

다음 목표를 정할 때 가치관 표를 먼저 보면 공허함이 줄어듭니다.

---

## 사례: "제 강점은 없는 줄 알았어요"

*(실제 사례를 바탕으로 각색했습니다.)*

4학년 J 학생은 자기소개서의 "본인의 강점" 문항에서 늘 막혔습니다. 1단계 질문에 답해 보니 친구들이 **"발표 자료 좀 정리해 줘"**라는 부탁을 자주 한다는 것을 알게 됐습니다. 본인은 당연하게 하던 일이 주변에는 어려운 일이었던 것입니다. "흩어진 정보를 한눈에 보이게 정리하는 힘"을 강점으로 정리하자 자소서와 면접 답변이 훨씬 구체적으로 바뀌었습니다.

## 자주 묻는 질문

**Q1. 강점 검사를 해 보는 게 좋을까요?**
도움이 됩니다. 학교 진로센터나 고용24의 직업심리검사를 활용해 보세요. 다만 검사 결과도 **실제 경험과 맞춰 보며** 해석하는 것이 중요합니다.

**Q2. 강점이 너무 평범한 것 같아요.**
평범해 보이는 강점도 **구체적인 경험**과 연결하면 충분히 설득력이 있습니다.

**Q3. 가치관이 자꾸 바뀌어요.**
자연스러운 일입니다. 학기마다 한 번씩 가치관 표를 다시 써 보세요. 변화 자체가 나를 이해하는 단서가 됩니다.

**Q4. 완벽주의가 너무 심해서 아무것도 못 하겠어요.**
마감이 짧은 작은 일부터 "일단 제출"을 연습해 보세요. 일상에 큰 지장이 있다면 학교 학생상담센터와 이야기해 보는 것도 좋습니다.

---

## 정리

1. 강점은 **남들은 힘든데 나는 덜 힘든 일**에서 찾으세요.
2. **가치관 순위 5개**를 정해 두면 선택의 기준이 됩니다.
3. 강점과 가치관을 **한 문장으로 연결**하고, 완벽주의는 **일단 제출**로 줄여 보세요.
