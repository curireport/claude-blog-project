# 전공이 안 맞는 대학생, 전공과 진로를 분리해 보세요

전공 수업은 그럭저럭 따라갑니다. 그런데 이 전공으로 취업할 자신은 없습니다.

관심 가는 분야는 네다섯 개인데 하나로 좁히지 못한 채 학년만 올라갑니다. 주변은 다 방향을 정한 것 같은데 나만 출발선에 서 있는 느낌입니다.

이건 전공을 잘못 고른 것이 아닐 수 있습니다. **전공과 진로를 하나로 묶어 두고, 방향을 한 번에 맞히려 하기 때문**입니다. 진로는 맞히는 것이 아니라 **작게 시도하면서 좁혀 가는 것**입니다.

> **📌 이 글의 핵심 3줄**
> 1. **전공은 출발점 중 하나일 뿐**, 같은 전공에서도 갈라지는 직무는 많습니다.
> 2. 관심사를 직업 이름이 아니라 **"하는 일" 단위로** 바꿔서 비교하세요.
> 3. 관심 분야마다 **작은 시도 하나**와 **탐색 기한**을 정하세요.

## 이런 고민을 하고 있나요?

- [ ] 전공은 맞는데 그 길로 일할 자신은 없다
- [ ] 졸업 후 하고 싶은 일이 구체적으로 떠오르지 않는다
- [ ] 관심 분야가 여러 개인데 하나로 못 좁힌다
- [ ] 정보는 많이 찾는데 직접 해 보거나 만나 본 적은 없다
- [ ] "확신이 서면 시작하겠다"며 미루는 중이다

---

## 진로가 안 잡히는 3가지 이유

### 1. 한 번에 정답을 찾으려 한다

"이거다" 싶은 확신이 먼저 와야 움직일 수 있다고 생각하면 탐색이 계속 미뤄집니다. 대부분의 확신은 **해 본 뒤에** 생깁니다.

### 2. 정보만 모으고 직접 부딪히지 않는다

직무 소개, 연봉, 후기를 다 읽어도 현직자와 이야기하거나 작게 해 보지 않으면 **실제로 어떤 느낌인지**를 알 수 없습니다. 그래서 판단이 서지 않습니다.

### 3. "전공 = 진로"라는 생각이 선택지를 좁힌다

같은 전공에서도 진로는 여러 갈래로 나뉩니다.

| 전공 예시 | 갈라지는 진로 예시 |
|---|---|
| 경영학 | 마케팅, 재무, 인사, 영업, 창업, 데이터 분석 |
| 국어국문학 | 출판·편집, 콘텐츠 기획, 홍보, 교육, 공공기관 |
| 생명과학 | 연구, 제약 영업, 품질 관리, 임상 지원, 과학 커뮤니케이션 |
| 컴퓨터공학 | 개발, 기획(PM), 데이터, 보안, 기술 영업 |

## 전공과 진로를 분리해서 찾는 4단계

### 1단계. 관심사를 '하는 일' 단위로 바꾸기

"콘텐츠에 관심 있다"는 말만으로는 비교가 안 됩니다. 실제로 **어떤 일을 하고 싶은지**로 쪼갭니다.

| 관심사 | 쪼갠 일 | 끌리는 정도 (1~5) |
|---|---|---|
| 콘텐츠 | 기획하기 | |
| | 글 쓰기 | |
| | 편집·디자인하기 | |
| | 데이터로 성과 분석하기 | |

점수가 높은 일들을 모아 보면, 서로 다른 관심사에 공통으로 들어 있는 **핵심 활동**이 보입니다.

### 2단계. 관심사마다 '작은 시도' 하나 정하기

| 시도 방법 | 드는 시간 | 예시 |
|---|---|---|
| 현직자 대화 | 30분~1시간 | 선배, 동아리 OB, 직무 멘토링 프로그램 |
| 특강·설명회 참석 | 2시간 | 학교 진로센터, 기업 설명회 |
| 짧은 프로젝트 | 2~4주 | 블로그 운영, 공모전, 작은 앱 만들기 |
| 단기 경험 | 1~3개월 | 인턴, 아르바이트, 대외활동 |

### 3단계. 탐색 기한 정하기

"언젠가 정해야지"는 불안만 키웁니다.
> **"이번 학기까지 세 가지를 시도하고, 두 가지로 줄인다."**

이처럼 기한과 숫자를 정해 두면 움직이기 쉬워집니다.

### 4단계. 진로 검사로 지도 그리기

학교 진로센터나 고용노동부 **워크넷(고용24)**의 직업심리검사를 활용해 보세요. 결과는 정답이 아니라 **어디부터 시도해 볼지 정하는 지도**입니다.

## 복수전공·전과·진로 전환, 무엇이 맞을까

| 방법 | 이런 경우에 맞아요 | 주의할 점 |
|---|---|---|
| **전공 유지 + 다른 직무 준비** | 전공 공부는 괜찮지만 직무만 다르게 가고 싶을 때 | 직무 관련 경험을 따로 쌓아야 함 |
| **복수전공·부전공** | 관심 분야가 분명하고 전공 지식이 필요할 때 | 학점 부담, 졸업 시기 확인 |
| **전과** | 전공 공부 자체가 맞지 않을 때 | 학교별 조건과 시기가 다름 |
| **휴학 후 탐색** | 방향을 정하려면 경험이 꼭 필요할 때 | 휴학 기간에 할 일을 미리 계획 |

*※ 복수전공·전과 조건은 학교마다 다릅니다. 소속 학교 학사 안내를 확인하세요.*

## 사례: 경영학과 3학년의 진로 실험

*(실제 사례를 바탕으로 각색했습니다.)*

경영학과 3학년 G 학생은 마케팅, 인사, 데이터 분석 중 무엇을 할지 2년째 고민만 하고 있었습니다. 세 분야의 현직 선배를 한 명씩 만나고, 데이터 분석은 짧은 온라인 프로젝트를 해 봤습니다. 한 학기 뒤 G 학생은 "숫자로 사람의 행동을 설명하는 일"이 가장 재미있다는 걸 알게 되었고, **마케팅 데이터 분석**으로 방향을 좁혔습니다.

## 자주 묻는 질문

**Q1. 4학년인데 지금 진로를 바꿔도 될까요?**
늦지 않습니다. 다만 시간이 제한적이니 작은 시도를 빠르게 여러 번 하는 방식이 좋습니다.

**Q2. 전공과 다른 직무로 취업이 가능한가요?**
많은 직무가 전공보다 **관련 경험과 역량**을 봅니다. 지원 직무에 맞는 경험을 하나라도 만들어 두세요.

**Q3. 관심 분야가 계속 바뀌어요.**
자연스러운 일입니다. 바뀌는 관심사들 사이에 **공통으로 남는 활동**을 찾아보세요.

**Q4. 현직자를 어떻게 만나나요?**
학교 진로센터의 멘토링 프로그램, 동아리 선배, 직무 커뮤니티, 기업 설명회를 활용해 보세요.

---

## 정리

1. 전공과 진로는 **같은 것이 아닙니다.** 분리해서 보세요.
2. 관심사를 **하는 일 단위로 쪼개고**, 분야마다 **작은 시도**를 하세요.
3. **탐색 기한**을 정하면 고민이 실행으로 바뀝니다.
