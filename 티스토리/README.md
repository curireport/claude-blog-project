# 티스토리 블로그 자료

구글 검색 유입과 광고 수익(애드센스·애드핏)을 목표로 하는 티스토리 블로그 자료입니다.
**미래온 성장연구소와 연결고리가 드러나지 않게** 운영합니다. 상담 안내, 자가진단, 카카오 채널, 네이버 블로그 링크는 넣지 않습니다.

## 추천 발행 순서 (2026년 10월 말 시작, 주 3편)

검색이 몰리는 시기가 가까운 글을 먼저 올리고, 그다음 허브 글과 그 하위 글을 묶어서 올립니다.

| 주차 | 원고 | 이유 |
|---|---|---|
| **1주** | 25 → 30 → 22 | 지금이 시즌 (수능 직후, 국가장학금 1학기 1차 신청, 겨울방학 준비) |
| 2주 | 13(허브) → 12 → 14 | 내신 5등급제 묶음 |
| 3주 | 15 → 16 → 17 | 성적·이수 기준 묶음 |
| 4주 | 21(허브) → 01 → 18 | 로드맵·과목 선택·수능 |
| 5주 | 19 → 20 → 27 | 수능 준비·세특·계열 |
| 6주 | 02 → 26 → 28 | 진로 탐색 묶음 |
| 7주 | 03 → 29 → 05 | 공부 습관·부모 대화 |
| 8주 | 06 → 07 → 04 | 부모 대화·마음 |
| 9주 | 08 → 09 → 11 → 10 | 대학생 묶음 |
| **봄 (4~5월)** | 23 → 24 | 여름방학·수시 원서 시즌 1~2개월 전 |

- **17번(고1 첫 중간고사)**은 3주차에 올리고, 이듬해 2월에 내용을 손봐서 맨 위로 다시 올리면 좋습니다.
- 각 원고 끝의 **"함께 읽으면 좋은 글 [발행 후 링크]"**는 해당 글을 발행한 뒤 실제 주소로 바꿉니다. 아직 안 올린 글이면 그 줄은 지우고 발행하고, 나중에 링크를 추가합니다.

## 원고 사용법

1. 원고 맨 위 `<!-- [발행 정보] -->` 블록에서 **퍼머링크, 메타 설명, 태그**를 티스토리 설정 칸에 옮깁니다.
2. 그 블록과 본문 속 `<!-- 광고 위치 -->`, 맨 아래 `<!-- [이미지 제안] -->`은 **모두 지우고** 본문만 붙여 넣습니다. (주석은 화면에 안 보여도 페이지 소스에 남습니다.)
3. 티스토리 에디터를 **마크다운 모드**로 바꾸면 표와 체크리스트가 그대로 들어갑니다.
4. 이미지는 제안을 참고해 넣고, **네이버 블로그에 쓴 사진은 쓰지 않습니다.**
5. 발행 전 `기획/02_네이버글_재가공_템플릿.md`의 **발행 전 체크리스트**와 **브랜드 분리 체크리스트**를 확인합니다.
