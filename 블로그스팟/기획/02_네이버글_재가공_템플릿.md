# 미래온 블로그 글 → 블로그스팟 글 재가공 템플릿

미래온 네이버 블로그에 올린 글(`자가진단해설_*.txt` 등)을 **구글 검색용 블로그스팟 글**로 다시 만드는 방법입니다.

---

## 1. 왜 "복사"가 아니라 "재가공"이어야 하나

- **중복 문서 위험**: 같은 글을 그대로 옮기면 검색엔진이 원본 하나만 남기고 나머지를 낮게 평가합니다. 네이버 글까지 손해를 볼 수 있습니다.
- **독자가 다름**: 네이버 독자는 미래온을 알고 들어온 사람이 많지만, 블로그스팟 독자는 **구글에 질문을 검색하고 들어온 처음 보는 사람**입니다.
- **목적이 다름**: 네이버 글은 "상담 신청"이 목표이고, 블로그스팟 글은 "질문에 완벽히 답해서 오래 읽히는 것(광고 수익)"이 유일한 목표입니다.
- **브랜드 분리**: 블로그스팟 블로그는 **미래온 성장연구소와 연결고리가 드러나지 않게** 운영합니다. 상담 안내나 미래온 링크는 넣지 않습니다.

## 2. 재가공 5원칙

| # | 원칙 | 미래온 원문 | 블로그스팟 재가공 |
|---|---|---|---|
| 1 | **제목을 검색 질문으로** | "기준이 없어서 막막한 겁니다" (공감형) | "고교학점제 과목 선택, 진로 안 정해졌다면 이렇게" (검색어 포함) |
| 2 | **자가진단 틀 걷어내기** | "B 영역 점수가 높게 나온 학생에게" | 자가진단 언급 완전 삭제 |
| 3 | **정보 층 추가 (전체의 30% 이상 새 내용)** | 마음·관점 위주 | 제도 설명, 표, 체크리스트, 예시, FAQ 추가 |
| 4 | **구조 바꾸기** | 신호 → 원인 → 해볼 것 → 상담 | 요약 → 개념 → 방법(단계) → 사례 → FAQ → 정리 |
| 5 | **문장 새로 쓰기** | 같은 문장 그대로 X | 핵심 메시지만 가져오고 문장은 모두 새로 |
| 6 | **미래온 흔적 지우기** | 미래온 이름, 고유 표현, 상담 안내 | 아래 '브랜드 분리 체크리스트'를 모두 통과 |

> 판단 기준: 원문과 나란히 놓았을 때 **같은 문단이 하나도 없어야** 합니다. 가져오는 것은 "핵심 통찰"과 "상담 현장 경험"뿐입니다.

## 3. 원문에서 가져올 것 / 버릴 것

**가져올 것 (원문의 자산)**
- 상담 현장에서 본 패턴 ("친구 따라 과목 고르기" 같은 실제 장면)
- 원문의 판단 기준 (예: 과목 선택 3순위). 단, **원문의 고유 표현은 다른 말로** 바꿉니다 (예: "현재 좌표 한 장" → "내 위치 정리표")
- 공감 문장 1~2개 (도입부에 짧게)

**버릴 것 / 바꿀 것**
- `━━━` 구분선, 이모지 과다 사용 → 소제목(H2, H3)으로 대체
- "○ 영역 점수가 높게 나온 분" → 삭제
- 해시태그 줄 → 블로거 **라벨**로 정리 (카테고리 1개 + 키워드 1~2개)
- Unsplash 이미지 안내 → 이미지 넣고 **대체 텍스트(alt)**에 키워드 포함
- "함께 읽으면 좋은 글 [링크]" → 블로그 내부 글 링크로 교체

## 4. 블로그스팟 글 기본 구조 (복사해서 쓰는 틀)

```
[제목] 메인 키워드 + 독자의 질문/고민 (30자 내외)
  예) 고교학점제 과목 선택, 진로가 안 정해졌다면 이렇게 고르세요

[도입 3~5줄]
  - 독자의 상황을 한 장면으로 (원문 공감 문장 활용)
  - 이 글을 읽으면 무엇을 알 수 있는지 한 줄 약속

[핵심 요약 박스]  ← 구글이 좋아하고, 바쁜 독자도 머무름
  - 이 글의 결론 3줄
```

## 5. 발행 전 체크리스트

**검색(SEO)**
- [ ] 제목 앞쪽에 메인 키워드가 있다
- [ ] 첫 문단 100자 안에 메인 키워드가 1번 나온다
- [ ] H2 소제목 4개 이상, 그중 2개 이상에 관련 키워드
- [ ] 본문 2,000자 이상 (공백 제외 기준 1,500자 이상)
- [ ] 이미지 2~4장, 대체 텍스트 입력
- [ ] 같은 클러스터 내부 링크 2개 이상 + 허브 글 링크
- [ ] 블로거 글 설정의 **검색 설명** 칸에 80~120자 요약 입력
- [ ] **맞춤 퍼머링크**를 영문으로 입력
- [ ] 라벨 2~3개 (카테고리 1개 + 키워드 1~2개)

**신뢰(E-E-A-T)**
- [ ] 실제 경험을 바탕으로 한 사례가 1개 이상 들어갔다 (기관명 없이)
- [ ] 제도 정보에 출처와 "○년 ○월 기준" 표기
- [ ] 원문과 같은 문단이 없다 (나란히 놓고 확인)

**브랜드 분리 (미래온 흔적 지우기)**
- [ ] "미래온", "성장연구소" 단어가 없다 (본문·라벨·이미지 파일명·대체 텍스트 모두)
- [ ] 카카오톡 채널, 자가진단 페이지, 네이버 블로그 링크가 없다
- [ ] 원문의 고유 표현("현재 좌표", "○ 영역", "상담 전 자가진단" 등)을 다른 말로 바꿨다
- [ ] 미래온 블로그에 쓴 이미지와 같은 이미지를 쓰지 않았다
- [ ] "상담을 하다 보면", "상담 문의" 같은 상담 안내 문구가 없다
- [ ] 원문을 올린 지 최소 2~4주 지난 뒤 발행한다 (같은 시기에 비슷한 글이 나란히 뜨지 않게)

**광고·가독성**
- [ ] 문단은 3~4줄 이내
- [ ] 표 또는 체크리스트 1개 이상
- [ ] 광고 위치 2~3곳 (요약 아래, 본문 중간, FAQ 아래)

## 6. 블로그스팟(블로거) 처음 세팅 (한 번만)

> 메뉴 이름은 블로거 화면 개편에 따라 조금씩 다를 수 있습니다.

0. **분리 계정**: 미래온과 다른 블로그 이름·프로필을 씁니다. 블로그 소개에도 기관명이나 연락처를 넣지 않습니다. 애드센스 정산 정보는 본인 명의로 해도 독자에게는 보이지 않습니다.
1. **블로그 만들기**: blogger.com → 새 블로그 → 이름·주소(`○○○.blogspot.com`) 정하기
2. **테마**: 반응형 기본 테마(예: Contempo, Essential 계열) 중 가벼운 것 선택, 모바일 보기 확인
3. **개인 도메인 연결 (권장)**: 도메인을 구입한 뒤 설정 › 게시 › **맞춤 도메인**에 입력하고, 도메인 업체에서 안내되는 CNAME 값을 등록 → **HTTPS 사용** 켜기
4. **검색 설명 켜기**: 설정 › 메타 태그 › **검색 설명 사용** 켜기 (이걸 켜야 글마다 검색 설명 칸이 생깁니다)
5. **필수 페이지**: 페이지 메뉴에서 **개인정보처리방침**, **블로그 소개**, **문의** 페이지 만들기 (애드센스 승인에 도움)
6. **검색 등록**: 구글 서치콘솔(사이트맵 `/sitemap.xml` 제출), 네이버 서치어드바이저, 다음 웹마스터도구에 블로그 등록
7. **애드센스**: 왼쪽 메뉴 **수익 창출(Earnings)**에서 애드센스 계정 연결·신청. 정성 들인 글 15~20편이 쌓인 뒤 신청 권장
8. **광고 설정**: 블로그스팟은 티스토리와 달리 **자동 광고의 앵커·전면(비네트) 광고를 쓸 수 있습니다.** 다만 너무 많으면 체류 시간이 줄어드니 처음엔 기본값으로 두고 서치콘솔·애드센스 수치를 보며 조정

## 8. 재가공용 AI 프롬프트 (Claude에 그대로 붙여 넣기)

```
아래는 내가 네이버 블로그에 올린 원문이야.
이 글을 구글 검색용 블로그스팟 글로 재가공해 줘.

[조건]
1. 메인 키워드: {메인 키워드}
2. 제목은 검색 질문형, 메인 키워드를 앞쪽에
3. 원문과 같은 문장·문단은 쓰지 말고, 핵심 통찰과 상담 경험만 가져올 것
4. 원문에 없는 정보 층을 30% 이상 추가: {추가할 정보 층}
   - 제도 정보는 "○년 ○월 기준"과 출처 기관을 표기
5. 구조: 도입 → 핵심 요약 3줄 → 개념 정리 → 원인 → 단계별 방법 → 사례(익명) → FAQ 4개 → 정리 → 관련 글
   - 원문 기관명(미래온 성장연구소), 연락처, 자가진단 안내, 상담 안내 문구는 모두 빼고
   - 원문의 고유 표현("현재 좌표", "○ 영역" 등)은 다른 말로 바꿀 것
6. 본문 2,500자 이상, 문단은 3~4줄 이내, 표나 체크리스트 1개 이상
7. 광고 위치를 <!-- 광고 --> 로 3곳 표시
8. 마지막에 검색 설명(100자 내외), 영문 퍼머링크, 라벨 3개, 이미지 3장 제안(대체 텍스트 포함)

[원문]
{여기에 네이버 원문 붙여 넣기}
```

> AI 결과물은 **초안**입니다. 발행 전에 ① 실제 상담 경험 한 줄 추가, ② 제도 정보 공식 발표와 대조, ③ 직접 찍은 사진 1장 이상 넣기. 이 세 가지가 구글 노출을 좌우합니다.
