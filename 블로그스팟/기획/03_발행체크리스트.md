## 1. 매번 하는 체크리스트 (글 1편마다)

### 발행 전 (원고 손보기, 약 30분)
- [ ] 아래 **2번 표**에서 이 글의 **영문 퍼머링크·라벨** 확인, 원고 맨 위 **발행 정보**에서 검색 설명 복사해 두기
- [ ] 아래 **편별 체크**의 사실 확인 항목 공식 사이트와 대조
- [ ] 직접 겪은 경험 1~2줄 추가 (누구 이야기인지 알 수 없게)
- [ ] **미래온 흔적 0개**: "미래온", "성장연구소", "상담 문의", 카카오 채널·네이버 링크 없음
- [ ] 이미지 2~4장 준비 (네이버 블로그에 쓴 사진은 쓰지 않기), 1장 이상 직접 촬영·제작

### 발행 (블로거 글쓰기 화면, 약 20분)
- [ ] 블로거 › **새 글** → 제목 입력
- [ ] 구글 문서에서 본문(제목 아래 ~ "함께 읽으면 좋은 글")을 복사해 **작성 보기**에 붙여 넣기 (발행 메모·광고 위치·이미지 제안은 빼기)
- [ ] 소제목이 **제목/부제목** 서식으로 들어갔는지 확인 (H2·H3 역할)
- [ ] 미리보기에서 **표·체크박스가 깨지지 않는지** 확인 (깨지면 표를 다시 붙여 넣거나 HTML 보기에서 정리)
- [ ] 이미지 넣고 **대체 텍스트(alt)** 입력 (원고의 이미지 제안 참고)
- [ ] 오른쪽 글 설정 › **라벨**: 아래 2번 표의 카테고리 라벨 + 키워드 1~2개
- [ ] 글 설정 › **퍼머링크 › 맞춤 퍼머링크**: 아래 2번 표의 영문 주소 입력
- [ ] 글 설정 › **검색 설명**: 원고의 검색 설명 붙여 넣기 (설정에서 검색 설명 사용을 켜야 보임)
- [ ] 관련 글 링크: 이미 발행된 글은 실제 주소로 바꾸고, 아직 없는 글은 그 줄 삭제
- [ ] **게시**

### 발행 후 (약 10분)
- [ ] 구글 **서치콘솔 → URL 검사 → 색인 생성 요청**
- [ ] 아래 편별 체크의 **"이 글 링크를 추가할 기존 글"**에 들어가 관련 글 줄 추가
- [ ] 휴대폰으로 열어 표·이미지가 잘 보이는지 확인
- [ ] 아래 **발행 기록표**에 날짜·주소 적기
