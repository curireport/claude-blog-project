━━━━━━━━━━━━━━━━━━━━━━━━━━━

**상담 신청 전에 해보는 자가진단 (대학생·졸업예정자용)**
"막연한 불안"을 "다룰 수 있는 주제"로 바꿔 봅니다

취업, 진로, 관계, 번아웃.
여러 개가 한꺼번에 얽혀 있으면
무엇부터 손대야 할지 모르는 상태가 됩니다.

이 자가진단은 그 덩어리를 네 갈래로 나눠
지금 어디에 무게가 실려 있는지 확인하는 도구입니다.

소요 시간은 3분 정도입니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️ 이 자가진단은 상담을 준비하기 위한 참고용 체크리스트입니다.
정식 심리검사나 진단을 대체하지 않으며,
점수가 높다고 문제가 있다는 뜻이 아니라
"지금 마음이 어디에 가 있는지"를 보여줄 뿐입니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 점수 매기는 법

각 문항이 요즘 나에게 얼마나 해당되는지 숫자로 적습니다.

  0 = 전혀 아니다
  1 = 가끔 그렇다
  2 = 자주 그렇다
  3 = 매우 그렇다

영역별 네 문항을 더하면 영역 점수(0~12점)가 됩니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ A 영역 · 진로 방향

A1. 전공은 정했지만 이 길이 나에게 맞는지 확신이 없다. ( )
A2. 졸업 후 무엇을 하고 싶은지 구체적으로 떠오르지 않는다. ( )
A3. 관심 분야가 여러 개인데 하나로 좁히지 못하겠다. ( )
A4. 주변은 방향을 잡은 것 같은데 나만 정체된 느낌이다. ( )

A 영역 합계: (       ) / 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ B 영역 · 취업 준비와 실행

B1. 무엇부터 준비해야 할지 우선순위가 서지 않는다. ( )
B2. 자기소개서에 쓸 내 경험·강점이 무엇인지 모르겠다. ( )
B3. 지원하려는 직무가 실제로 어떤 일을 하는지 잘 모른다. ( )
B4. 준비를 미루다가 마감에 쫓기는 일이 반복된다. ( )

B 영역 합계: (       ) / 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ C 영역 · 마음과 관계

C1. 요즘 불안하거나 무기력한 상태가 이어진다. ( )
C2. 번아웃처럼 의욕이 완전히 꺼진 느낌이다. ( )
C3. 대인관계나 연애에서 반복되는 어려움이 있다. ( )
C4. 중요한 선택 앞에서 결정을 계속 미루게 된다. ( )

C 영역 합계: (       ) / 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ D 영역 · 자기이해

D1. 내 강점과 가치관을 한두 문장으로 설명하기 어렵다. ( )
D2. 남들의 기준에 맞추다 보니 내가 원하는 게 흐려졌다. ( )
D3. 완벽하게 준비되지 않으면 시작하지 못한다. ( )
D4. 성취를 해도 만족보다 공허함이 남을 때가 있다. ( )

D 영역 합계: (       ) / 12

■ 결과 1 · 영역 점수로 보는 우선순위

  0~3점  → 지금은 큰 어려움이 없는 영역입니다.
  4~7점  → 한 번 짚어볼 만한 영역입니다.
  8~12점 → 상담에서 우선 다루면 좋은 영역입니다.

점수가 가장 높은 영역이 지금 가장 무게가 실린 곳입니다.
A와 B가 함께 높으면 "방향이 안 잡혀서 실행이 안 되는" 경우가 많고,
C와 D가 함께 높으면 "마음의 에너지부터 회복이 필요한" 경우가 많습니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 결과 2 · 영역별 추천 상담 분야

A 영역(진로 방향) → 진로 탐색 상담
  STRONG 직업흥미검사 기반 방향 설계, 관심 분야 좁히기

B 영역(취업 준비와 실행) → 취업·자소서·면접 코칭
  준비 우선순위 정리, 자소서 소재 발굴, 직무 탐색, 면접 준비

C 영역(마음과 관계) → 심리·관계 상담
  불안, 번아웃, 대인관계, 연애, 의사결정 — 임상심리 전문가 상담

D 영역(자기이해) → 진로 탐색 상담 + 심리 상담
  강점·가치관 정리, 완벽주의·비교 심리, 공허함 다루기

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 결과 3 · 전체 점수로 보는 지금 상태

네 영역 합계(0~48점)를 확인합니다.

  0~12점  → 전반적으로 안정적입니다.
            방향 점검 위주의 단회 상담으로도 충분할 수 있습니다.

  13~28점 → 몇 가지가 겹쳐 있는 상태입니다.
            상담에서 우선순위를 정리하면 준비가 한결 수월해집니다.

  29~48점 → 여러 영역이 함께 얽혀 있는 상태입니다.
            혼자 밀어붙이기보다 상담으로 순서를 잡는 것을 권합니다.

※ 점수는 우열이 아니라, 어디부터 이야기할지 정하는 참고선입니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 상담 전에 정리해 두면 좋은 3가지

1. 요즘 머릿속에 가장 자주 떠오르는 고민을 한 문장으로 적어보세요.

2. 그 고민이 시작된 시점이나 계기가 있다면 언제였나요?

3. 이번 상담이 끝났을 때 "이건 정리됐다" 하고 싶은 것은 무엇인가요?

■ 상담 신청 방법

가장 점수가 높았던 영역과 위 3가지 답을 함께
카카오톡 채널이나 블로그 댓글로 남겨주세요.
신청 확인 후 1~2일 내로 일정과 사전 설문을 안내드립니다.

첫 상담은 50분 내외이며, 대면·화상·전화 중 편한 방식으로 진행합니다.
